How the numbers are worked out
  • Innovation is a standing total: the labs hold it at a level set by their workers, and tech costs are held out of it (or out of knowledge) for as long as you keep the tech.
  • Clay tech kept anyway: clay tech you'd keep for other reasons (pottery, bricks, trade) counts as already paid. At 0, all clay tech is charged to the labs. Clay tech costs and gains are both innovation, so the calculator picks the best level exactly.
  • Lab output per worker = (1 + upgrade [+50% / +100%] + tools [+25% per level] + Laboratory efficiency [+40% per level] + experience + noble) × race. Clay in stock doubles the whole room (×2).
  • Education (×1 to ×2) multiplies the city's total innovation, not the lab room itself, so it adds innovation without burning more clay. Clay tech costs stay the same, so a more educated city gets more for each point spent.
  • Lab tech slider order: the lab tree branches, so the slider uses the best-value order per knowledge spent: Improved Laboratory, Laboratory Tools 1, Advanced Laboratory, Laboratory Efficiency 1–5, then Laboratory Tools 2. Tools 2 gives the least per point, so it comes last. The one state the slider can't show is Tools 2 taken before Advanced Laboratory. The clay tree is a straight chain in the game.
  • Clay burned = 0.75 per lab worker per day × that worker's full output, including the ×2. Better labs burn more clay.
  • Claypit output = 1.5 clay per miner per day × deposit (0.9 to 1.1) × (1 + clay techs + upgrade [+100% / +200%] + tools [+25% per level] + experience + noble) × race.
  • Experience: labs gain up to +250% as lab workers rise from 50 to 2,000. Claypits gain up to +100% from 50 to 1,000. Worked out from the split shown.
  • Noble office ("Master of …"): +250%. With the tick alone it covers every worker. Add a count and rank to apply the game's cap of 50 × (1 + 2 × rank) workers per noble.
  • Tools are assumed fully stocked once researched. Haulers = miners × logistics overhead, rounded up. If clay runs short, only that share of the labs gets the ×2.
  • ⓘ verdicts on lab tech convert its knowledge cost at about 1 admin ≈ 1.4 knowledge ≈ 1.9 innovation: what each point costs in workers once the rooms are well researched. Green is 1.25× or better, orange 0.8–1.25×, red below 0.8×.
  • Not modelled: room degradation, workload and distance penalties, tool wear and maintenance, the furniture and resource costs of building upgrades, and flat bonuses such as city rank (they add the same with or without clay, so they don't change the answer, but the percentages leave them out).
